# QingToolbox 0.2.6-alpha

QingToolbox 0.2.6-alpha is the next Preview host boundary for the Web module UI. It validates an in-place upgrade from the published `v0.2.5-alpha` host and keeps the native fallback available for genuine runtime failures.

## Highlights

- Web module hosting is now reported under a distinct host version boundary.
- The installer owns and validates the immutable WebUI asset tree, removing only obsolete files recorded by the previous host payload manifest.
- Upgrade validation requires the Web Shell to complete its existing acknowledged Ready handshake; a responsive native fallback alone is not considered a successful upgrade.
- User settings, modules, module data, cache, and unknown user-owned files remain outside host-owned cleanup.
- Concrete modules are not bundled with the host installer or host Release and remain independently delivered as `.qmod` packages.

## 简体中文

- Web 模块宿主版本边界从公开的 `v0.2.5-alpha` 之后开始生效。
- 安装器严格维护 Host-owned WebUI 资源树，并依据上一公开版本的 payload manifest 精确清理过期哈希文件。
- 升级验证必须完成现有 Web Shell Ready 握手；仅显示可响应的 Native WPF fallback 不算升级成功。
- 设置、模块、模块数据、缓存和未知用户文件继续保留。
- 具体模块不随宿主安装器或宿主 Release 捆绑，继续通过独立 `.qmod` 交付。

## Known limitations

- This remains an Alpha release; the installer and module packages are not digitally signed.
- Automatic Production module-update installation remains unavailable.
- A genuinely corrupted or unavailable Web asset still uses the native WPF fallback by design.

## English

QingToolbox 0.2.6-alpha establishes the Web module host boundary after the published `v0.2.5-alpha` Preview. In-place upgrade validation verifies exact host-owned WebUI replacement, acknowledged Web Ready state, and preservation of user-owned settings, modules, data, cache, and unknown files.
