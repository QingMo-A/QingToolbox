# QingToolbox 0.2.3-alpha

QingToolbox 0.2.3-alpha 是面向早期测试用户的 Alpha 更新。本版本让 Vue 工作区的外观选择同步到原生 WPF 标题栏，修复切换浅色、深色或跟随系统模式后标题栏颜色不一致的问题。

## 简体中文

### 主要变化

- Vue 工作区切换浅色、深色或跟随系统外观时，原生标题栏会同步更新背景、文字、分隔线以及窗口按钮反馈颜色。
- 跟随系统模式会读取 Windows 应用外观偏好，并在系统外观变化时刷新标题栏。
- 主题通知仅接受当前已验证的本地 WebView 会话，不改变现有 Bridge protocol v4、安全握手或模块生命周期语义。
- 安装器支持从官方 `v0.2.2-alpha` 原地升级，并继续保留用户设置、用户模块和模块数据。
- 覆盖升级会清理 0.2.2-alpha 已被替换的宿主文档与 Web 哈希资产。
- 具体模块不随宿主安装器或宿主 Release 捆绑，继续通过独立 `.qmod` 交付。

### 已知限制

- 本版本仍为 Alpha，安装器与模块包尚未数字签名。
- Production 模块自动更新安装仍未开放。
- 尚未执行的人工环境验收继续保持 Not Run 或 Blocked。

## English

### Highlights

- The native WPF title bar now follows the Vue workspace light, dark, and system appearance modes, including its background, text, divider, hover, and pressed colors.
- System mode reads the Windows app appearance preference and refreshes the title bar when that preference changes.
- Theme notifications are accepted only from the current verified local WebView session and do not change Bridge protocol v4, its security handshake, or module lifecycle semantics.
- The installer supports an in-place upgrade from the official `v0.2.2-alpha` release while preserving settings, user modules, and module data.
- In-place upgrades clean host documentation and hashed Web assets that were replaced after 0.2.2-alpha.
- Concrete modules are not bundled with the host installer or host Release and remain independently delivered as `.qmod` packages.

### Known limitations

- This remains an Alpha release; the installer and module packages are not digitally signed.
- Automatic Production module-update installation remains unavailable.
- Manual environment checks that have not been performed remain Not Run or Blocked.
