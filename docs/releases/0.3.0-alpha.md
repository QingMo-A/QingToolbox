# QingToolbox 0.3.0-alpha

The first Rust/Tauri 2/Vue 3 host preview. This release replaces the WPF host under the existing QingToolbox Windows product identity. It is **unsigned**; Windows may show an Unknown publisher or SmartScreen warning. Download only from this repository's GitHub Release and verify the supplied SHA256 sidecar.

## What's new

- Native process-isolated modules with distinct load, enable, disable, unload and delete actions. The installer bundles the compatible Tauri modules; legacy WPF DLL modules are not compatible.
- Refreshed Vue workspace, custom title bar, frameless floating badge, improved font application and module-window behaviour.
- Qing Launcher 0.3.0 with a centered transparent overlay, desktop/custom/initial-letter views, drag-to-sort and folders, native icon loading, hotkey capture and built-in Everything search feedback.
- Updated QingTransfer, Screen Pin, Window Topmost, PowerGuard, Text Tools and PDF modules, plus the Web Module Canary used for module verification.
- Existing QingToolbox product AppId, so a normal installer can update an existing WPF or Tauri installation instead of creating a second uninstall entry. On first WPF migration, the installer backs up the registered installation and shared settings before replacement and retires the old host's owned startup registration. Existing user settings and module data are preserved.

## Install and compatibility

Use `QingToolbox-0.3.0-alpha-win-x64-tauri-setup.exe` on Windows x64. Exit QingToolbox completely before installation. The installer and matching `.sha256` file are the host Release assets. The same native modules are available separately as `.qmod` packages for Tauri installations; do not import them into the WPF host or substitute older WPF `.qmod` packages for these process modules.

The installer leaves historical WPF files that are outside the new Tauri payload in place for rollback; the backed-up copy is under `%LOCALAPPDATA%\QingToolbox-MigrationBackups`. Do not delete the backup until the migrated installation and data have been checked. First-migration rollback is manual. Module update catalogs for the old WPF host are not redirected to these incompatible native packages.

This is an alpha release. It is not code-signed, and real-user WPF upgrade, repair, uninstall and SmartScreen behaviour may vary by environment. Report issues with the installed version and whether this was a clean install or WPF upgrade.
