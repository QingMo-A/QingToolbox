# QingToolbox 0.2.2-alpha

QingToolbox 0.2.2-alpha 是面向早期测试用户的 Alpha 更新。本版本将经过验证的 Vue 3 工作区用于正式安装版，同时保留原生 WPF 安全回退。

## 简体中文

### 主要变化

- 正式安装版默认显示 Vue 3 工作区；WebView2、资源验证或 ready 握手失败时自动恢复原生 WPF 工作区。
- 首页、模块、运行中、日志与设置页面沿用当前现代化 Vue 界面。
- 宿主更新横幅和设置页更新中心已接入 Vue，继续支持检查、下载、取消与安装。
- 宿主更新的大小限制、SHA256 sidecar、文件哈希复核、用户确认和 Inno Setup 交接仍由 C# 宿主负责。
- 开发诊断和已验证模块更新安装仍仅限 Development 环境，不会在 Production 中开放。
- 安装器支持从官方 `v0.2.1-alpha` 原地升级并保留用户设置、用户模块及模块数据。
- 具体模块不随宿主安装器或宿主 Release 捆绑，继续通过独立 `.qmod` 交付。

### 已知限制

- 本版本仍为 Alpha，安装器与模块包尚未数字签名。
- Production 模块自动更新安装仍未开放。
- 尚未执行的人工环境验收继续保持 Not Run 或 Blocked。

## English

### Highlights

- The installed Production app now uses the verified Vue 3 workspace by default and safely falls back to native WPF if WebView2, asset validation, or the ready handshake fails.
- Home, Modules, Running, Logs, and Settings retain the current modern Vue experience.
- The host-update banner and Settings update center support checking, downloading, cancelling, and installing updates from Vue.
- Size limits, the SHA256 sidecar, file-hash revalidation, user confirmation, and Inno Setup handoff remain owned by the C# host.
- Development Diagnostics and verified module-update installation remain Development-only.
- The installer supports an in-place upgrade from the official `v0.2.1-alpha` release while preserving settings, user modules, and module data.
- Concrete modules are not bundled with the host installer or host Release and remain independently delivered as `.qmod` packages.

### Known limitations

- This remains an Alpha release; the installer and module packages are not digitally signed.
- Automatic Production module-update installation remains unavailable.
- Manual environment checks that have not been performed remain Not Run or Blocked.
