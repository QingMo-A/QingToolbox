# QingToolbox 0.2.1-alpha

QingToolbox 0.2.1-alpha 是面向早期测试用户的 Alpha 版本。

## 简体中文

### 主要变化

- QingToolbox 现在可以检查官方宿主更新，并在用户确认后安全准备安装器。
- 原生首页会记住最多五个真正最近使用的模块，并提供一键启动。
- 一键启动按需完成加载、启用和打开；只有最终窗口成功打开才会记录成功。
- 首批三个模块 TextTools、PowerGuard 和 WindowTopmost 已经单独完成适配和验证，将由项目所有者通过独立模块交付路径提供；它们不随宿主安装器或宿主 Release 捆绑。
- 模块窗口和原生界面的兼容性与反馈得到改进。
- 安装器支持从已发布的 `v0.1.0-alpha` 原地升级并保留用户设置、模块及数据。`0.2.0-alpha` 只是未发布的 Preview 2 内部开发目标。

### 安全与行为

- 更新不会自动安装，必须由用户明确下载并确认安装。
- 安装器大小、同名 SHA256 sidecar 和文件 SHA256 均会被验证。
- 模块不会因安装、启动或刷新而自动加载或运行。
- PowerGuard 的系统操作只有在用户明确配置后才会执行。
- 本版本仍为 Alpha，安装器与模块包尚未进行数字签名。

### 已知限制

- Production 模块自动更新安装仍未开放。
- Production Web UI 仍未开放。
- 尚未完成的人工验收继续标记为 Not Run 或 Blocked。

## English

### Highlights

- QingToolbox can check official host releases and safely prepare an installer after explicit user action.
- The native home remembers up to five genuine recently used modules and offers one-click launch.
- One-click launch loads, activates, and opens as needed, and succeeds only after the module window opens.
- Three starter modules—TextTools, PowerGuard, and WindowTopmost—have been prepared and validated separately. The project owner will provide them through an independent module-delivery path; they are not bundled with the host installer or host Release.
- Native module-window compatibility and user feedback have been refined.
- The installer supports an in-place upgrade from the published `v0.1.0-alpha` while preserving user settings, modules, and data. `0.2.0-alpha` was an unpublished internal Preview 2 target.

### Safety and behavior

- Updates are never installed automatically; download and installation require explicit confirmation.
- Installer size, the same-name SHA256 sidecar, and the downloaded file hash are verified.
- Modules are not loaded or started automatically by installation, startup, or refresh.
- PowerGuard performs system actions only after explicit user configuration.
- This remains an Alpha release; the installer and module packages are not digitally signed.

### Known limitations

- Automatic Production module-update installation remains unavailable.
- Production Web UI remains unavailable.
- Manual checks that have not been performed remain Not Run or Blocked.
