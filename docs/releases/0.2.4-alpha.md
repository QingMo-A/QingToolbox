# QingToolbox 0.2.4-alpha

QingToolbox 0.2.4-alpha 是面向早期测试用户的安装可靠性修复。本版本解决 QingToolbox 在关闭到通知区域时，安装器无法自动结束旧进程并覆盖升级的问题。

## 简体中文

### 主要变化

- Windows Restart Manager 发出安装维护关闭信号后，QingToolbox 会绕过普通关闭按钮的“最小化到通知区域”设置，并执行现有的完整退出清理流程。
- 完整退出会依次清理通知区域、悬浮标、模块窗口、模块辅助进程和运行时，再结束宿主进程。
- 安装器为尚不支持维护关闭信号的 0.2.3-alpha 及更早版本保留受控强制关闭兜底。
- 安装器会检查 Shell、ModuleHost 和 StartupMaintenance 宿主可执行文件的占用情况。
- 支持从官方 `v0.2.3-alpha` 原地升级，并继续保留用户设置、用户模块和模块数据。
- 具体模块不随宿主安装器或宿主 Release 捆绑，继续通过独立 `.qmod` 交付。

### 已知限制

- 本版本仍为 Alpha，安装器与模块包尚未数字签名。
- Production 模块自动更新安装仍未开放。
- 尚未执行的人工环境验收继续保持 Not Run 或 Blocked。

## English

### Highlights

- QingToolbox now recognizes Windows Restart Manager maintenance shutdowns, bypasses the normal close-to-notification-area preference, and runs its existing orderly exit pipeline.
- The orderly exit cleans up the notification area, floating badge, module windows, module helper processes, and runtime before the host exits.
- The installer retains a controlled force-close fallback for 0.2.3-alpha and earlier versions that do not recognize maintenance shutdown messages.
- Installer in-use detection covers the Shell, ModuleHost, and StartupMaintenance host executables.
- The installer supports an in-place upgrade from the official `v0.2.3-alpha` release while preserving settings, user modules, and module data.
- Concrete modules are not bundled with the host installer or host Release and remain independently delivered as `.qmod` packages.

### Known limitations

- This remains an Alpha release; the installer and module packages are not digitally signed.
- Automatic Production module-update installation remains unavailable.
- Manual environment checks that have not been performed remain Not Run or Blocked.
