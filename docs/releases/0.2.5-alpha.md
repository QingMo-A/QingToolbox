# QingToolbox 0.2.5-alpha

QingToolbox 0.2.5-alpha 是面向早期测试用户的界面个性化更新。本版本新增可组合外观预设、受控字体选择与导入，并让原生标题栏、Vue 工作区和共享控件保持一致。

## 简体中文

### 主要变化

- 新增 Qing 默认、霓虹电路、绿线、极光流和 Qing Nova 五套外观预设，并为按钮、输入框、选择框、开关、单选控件和焦点状态提供一致的主题反馈。
- 支持搜索并选择 Windows 已安装字体，也可以导入 `.ttf`、`.otf` 或 `.ttc` 字体文件；导入文件会复制到 QingToolbox 管理的隔离目录，避免原文件被移动或删除后失效。
- 系统字体目录首次读取后会缓存，用户可以显式刷新；导入字体不会强制重新扫描全部系统字体。
- 字体和外观更改会同步到 Vue 工作区与原生 WPF 标题栏，并保留恢复默认入口。
- Vue 模块列表、首页、运行中页面和快速打开现在可以显示宿主安全投影的模块 SVG 图标，无效图标仍使用安全回退。
- 改进侧边栏图标对齐、标题栏按钮状态、窗口圆角和桌面悬浮标的位置恢复。
- 新增双重版本确认的本地发布交接入口，由 GitHub Actions 在精确源码提交上构建并验证安装器。
- 支持从官方 `v0.2.4-alpha` 原地升级，并继续保留用户设置、用户模块和模块数据。
- 具体模块不随宿主安装器或宿主 Release 捆绑，继续通过独立 `.qmod` 交付。

### 已知限制

- 本版本仍为 Alpha，安装器和模块包尚未数字签名。
- Production 模块自动更新安装仍未开放。
- 未执行的人工环境检查继续保持 Not Run 或 Blocked。

## English

### Highlights

- Added five composable appearance presets with theme-specific controls, focus feedback, and consistent shared component states.
- Added searchable Windows font selection and managed `.ttf`, `.otf`, and `.ttc` imports. Imported files are copied into an isolated QingToolbox-owned directory.
- Cached the installed-font catalog after its first scan and added an explicit refresh action without forcing a rescan after every import.
- Synchronized font and appearance changes across the Vue workspace and native WPF title bar, with a reliable Restore default action.
- Projected validated module SVG icons into the Vue home, module, running, and Quick Open views while retaining a safe fallback.
- Refined sidebar icon alignment, caption-button states, window corners, and floating-badge placement restoration.
- Added a double-confirmed local hand-off that asks GitHub Actions to build and validate the installer from the exact source commit.
- Supports an in-place upgrade from the official `v0.2.4-alpha` release while preserving settings, user modules, and module data.
- Concrete modules are not bundled with the host installer or host Release and remain independently delivered as `.qmod` packages.

### Known limitations

- This remains an Alpha release; the installer and module packages are not digitally signed.
- Automatic Production module-update installation remains unavailable.
- Manual environment checks that have not been performed remain Not Run or Blocked.
