# QingToolbox 0.3.4-alpha

Windows x64 · Rust + Tauri 2 + Vue 3 · Module API 1 · **Unsigned alpha**

## 简体中文

### 本次更新

- 修复工具箱内更新的下载可用性与安装器退出通信。覆盖安装请求正在运行的工具箱正常退出，确认退出后再替换程序文件；兼容旧版带 UTF-8 BOM 的生产清单。
- 优化设备连接稳定性：短暂发现/探测失败保留端点恢复机会，握手完成并收到确认后才更新认证在线状态，支持幂等在线探测的多地址重试。补充握手、端点、管理确认和恢复过程的脱敏日志。
- 修复切换页面后重复显示升级/降级关系结果的问题，不再要求用户靠重新配对来消除旧提示。设备关系、在线状态、电量和通知转发继续遵循既有配对与授权规则。
- 文件传输保留在已连接设备旁。PC 发送弹窗支持拖放文件或点击区域选择文件，选择后直接请求接收端确认；显示可读的 KB/MB/GB、进度和简洁的传输结果。自动接收成功或失败时显示工具箱信息弹窗。
- 多条信息弹窗采用紧凑的重叠卡片：最新消息完整显示，旧消息露出一部分；各自独立倒计时，鼠标悬停暂停该卡片并将其前置，移出后继续。关闭卡片后其余卡片补位，四角布局及边缘进入/退出动画沿用窗口设置。
- 加入持久化模块日志，记录加载、启用、停用、卸载、运行状态、进程错误及限流的标准错误输出，便于排查再次启用失败。模块操作失败显示更明确的原因；不记录模块协议业务载荷或握手凭据。

### 安装与升级

安装包：`QingToolbox-0.3.4-alpha-win-x64-tauri-setup.exe`，附同名 `.sha256` 校验文件。

本版本可覆盖既有 QingToolbox 安装，保留用户设置、已安装模块、模块数据和设备配对记录。安装包为 **host-only**，不内置模块，也不包含安卓 APK。

模块继续通过 `modules` 分支单独安装和更新。Qing Launcher 0.3.3 已在该分支提供可配置的 Everything 结果数量（默认 200）、可选分批加载（默认关闭）和 `/` 指令补全；它不是本安装包的一部分。

本版本未数字签名，Windows 可能提示未知发布者或 SmartScreen。请仅从官方仓库下载并核对 SHA-256。跨设备行为仍需在实际设备与网络中验证；本版本不提供远程控制，也不承诺消除所有网络波动。

## English

- Repair in-app host update downloads and graceful installer shutdown coordination, including compatibility with older UTF-8 BOM production manifests.
- Improve device endpoint recovery and authenticated presence: retain endpoints through transient discovery failures, require handshake acknowledgement before marking peers online, and retry only idempotent probes across addresses. Add redacted transport and acknowledgement diagnostics.
- Consume relationship-change notices so navigation does not replay old upgrade/demotion results.
- Keep file sending attached to an already paired device. Support drag-and-drop and click-to-select, request receiver approval after selection, show readable file sizes and progress, and notify automatic receive success/failure.
- Display concurrent notifications as compact overlapping cards with independent countdowns, hover pause/front placement, gap closure and screen-edge entrance/exit animations.
- Persist bounded module lifecycle/error/stderr diagnostics and show more specific operation failures without logging business protocol payloads or handshake credentials.

The Windows x64 installer is **host-only and unsigned**, with a SHA-256 sidecar. In-place upgrades preserve settings, installed modules, module data and device records. Android and modules are not bundled; Qing Launcher 0.3.3 is independently available from the `modules` branch. Module API remains 1. Remote control is not implemented; real-device/network acceptance remains necessary.
