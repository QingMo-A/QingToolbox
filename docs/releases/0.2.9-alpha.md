# QingToolbox 0.2.9-alpha

QingToolbox 0.2.9-alpha is a host-only Preview release after the published `v0.2.8-alpha`. It focuses on smoother recovery after long background sessions and enables the existing verified module-update transaction for official Production module updates while preserving installer-only host distribution.

## Release scope

- Reduces foreground restore stalls by suspending hidden Shell and module WebView2 surfaces, pausing hidden native animations, coalescing deferred module events, and bounding and parallelizing module-window lifecycle commands.
- Allows an explicit, user-confirmed update of an already installed module from host-authorized official metadata in Production and Development, with size and SHA256 verification, strict `qmod.json` staging, runtime quiescing, atomic replacement, rollback, and cold-start recovery.
- Accepts official module metadata with an omitted or explicit-null maximum host-version bound while retaining strict rejection of malformed bounds.
- Preserves exact host-owned obsolete-resource cleanup against the published `v0.2.8-alpha` payload. User settings, modules, data, cache, and unknown user-owned files remain outside that cleanup.
- The host Release remains installer-only. Concrete modules, including Qing Launcher 0.2.2, remain separately delivered as `.qmod` packages and are not bundled with the host installer or host Release.

## Release evidence

- Pre-handoff source validation: Preview validation run `32458823753` passed for the feature-complete host source before the version-only release preparation.
- The publishing handoff performs a fresh exact-HEAD candidate validation, including installer roundtrip and `v0.2.8-alpha → 0.2.9-alpha` in-place upgrade, before creating the tag and Release.
- Real-user install, upgrade, Repair, uninstall, signature and SmartScreen, and representative-environment acceptance remain Not Run or Blocked unless separately recorded in the acceptance checklist.

## Known limitations

- This remains an unsigned Alpha release and Windows SmartScreen may warn.
- Official module updates remain user-initiated. Automatic installation and arbitrary local same-ID `.qmod` overwrite remain unsupported.
- The previously observed native WPF fallback after an in-place installer handoff remains a manual acceptance risk; the automated upgrade gate verifies the installed WebUI file set and acknowledged Web Ready state but does not replace real-user acceptance.
- Concrete modules are not included in this host release and must be installed or updated independently.

## 简体中文

0.2.9-alpha 是继已发布 `v0.2.8-alpha` 之后的宿主独立预览版本，重点降低工具箱长时间后台运行后恢复悬浮窗、主面板和 Web 模块时的卡顿，并在 Production 中开放由宿主完整验证、用户明确确认的官方模块覆盖更新。更新仍由宿主负责校验、停用运行时、原子替换、回滚与冷启动恢复；不支持自动安装或手动同 ID 本地 `.qmod` 覆盖。

宿主安装器继续只清理上一公开版本中属于 Host 与 WebUI 的过期资源，不触碰用户设置、模块和数据。Qing Launcher 0.2.2 等具体模块不随宿主安装器或宿主 Release 捆绑，仍通过独立 `.qmod` 交付。
