# QingToolbox 0.3.3-alpha

Windows x64 · Rust + Tauri 2 + Vue 3 · Module API 1 · **Unsigned alpha**

## 简体中文

### 本次更新

- 修复官方模块仓库解析与下载：模块信息来自 `modules` 分支的 `modules/index.json` 和各模块目录内的 `update.json`，新安装包来自该目录下 `packages/` 的固定 Git 提交。不再要求模块创建 Release；历史 Release 包仍可安装。
- 下载验证官方仓库、完整 Commit SHA、模块目录、版本、文件大小、SHA-256 与包身份/API。raw 连接失败时可从 GitHub Contents API 读取同一提交、同一文件，不切换第三方镜像或可变版本。
- 单个模块清单出错只禁用该项并显示原因，不再导致整个仓库列表无法加载。
- 模块页支持本地导入、仓库下载并自动安装、已安装模块检查更新与覆盖更新；标题栏显示下载和安装状态，结束后使用信息弹窗提示。支持启动/定期更新检查及按模块关闭检查。
- 文件传输引擎正式编译进工具箱本体，不再依赖隐藏的 QingTransfer 模块。设备旁的传输入口连接既有对端；选择文件后发送请求，由接收端确认或按其自动接收设置处理。接收目录和自动接收设置在 PC 端可配置。
- 优化设备页布局、备注名、文件大小单位和传输结果提示；修复来件请求提示及部分设备传输端点状态问题。
- 修复关闭模块操作页面会卸载模块的问题；关闭页面不改变加载/启用状态，仍由显式停用、卸载、删除或更新操作控制生命周期。
- 整合共享模块 UI/皮肤样式，改善开发环境启动与增量构建缓存。Qing Launcher 0.3.1 单独在 `modules` 分支交付，不包含在本安装包中。

### 安装与升级

使用 `QingToolbox-0.3.3-alpha-win-x64-tauri-setup.exe`，可覆盖已有 WPF/Tauri QingToolbox 安装，沿用同一安装身份和原目录。安装器请求已运行的工具箱正常退出，退出确认后才覆盖文件；用户设置、已安装模块、模块数据和设备配对记录保留。

安装包仍为 **host-only**：不内置官方模块。旧工具箱需要升级本体一次，才能识别新分支包地址；之后模块独立更新，无需随本体发布或另建模块 Release。

本版本未签名，Windows 可能显示未知发布者或 SmartScreen 提示。仅从官方仓库下载，并核对同名 `.sha256` 文件。跨设备行为仍需在用户自己的设备和网络上验收；远程控制未实现，本版本不会宣称支持四路径远控。

## English

- Fix official module catalog parsing and support commit-pinned `.qmod` packages under the `modules` branch. Module Releases are no longer required; historical Release packages remain compatible.
- Verify repository, commit, module directory/version, size, SHA-256 and package identity/API. GitHub Contents API fallback requests the same immutable file.
- Isolate individual update-manifest failures instead of breaking the entire catalog.
- Ship repository download-and-install, module overwrite updates, startup/periodic update settings and per-module check preferences, with global progress and completion notifications.
- Compile device file transfer directly into the host, without a hidden QingTransfer module. Select files from an already connected device action, then request receiver approval or respect its auto-receive preference.
- Improve device layout, aliases, readable file sizes, incoming transfer prompts and completion states. Closing a module's management page no longer unloads its process.
- Update shared module appearance and development build reuse. Qing Launcher 0.3.1 remains a separate module package.

The Windows x64 installer is **host-only and unsigned**. In-place installation preserves settings, modules, device records and module data, and asks a running host to exit gracefully before replacing files. Verify the accompanying SHA-256 file. Remote control is not implemented; cross-device changes still require user acceptance on real devices.
