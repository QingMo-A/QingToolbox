# QingToolbox 0.2.8-alpha

QingToolbox 0.2.8-alpha is the next host-only Preview candidate after the published `v0.2.7-alpha`. It prepares the Web Module host interaction boundary used by modern modules while preserving the existing native fallback and installer-only distribution contract.

## Candidate scope

- Adds optional Web Module host window presentation and controlled external file-drop hooks.
- Keeps Standard Web module windows unchanged and supports transparent Overlay modules without changing the Web bridge protocol.
- Preserves the host-owned WebUI asset cleanup and Ready handshake introduced in `v0.2.7-alpha`.
- Concrete modules remain independently delivered as `.qmod` packages and are not bundled with the host installer or host Release.

- Real-user install/upgrade/Repair/uninstall, signature/SmartScreen, and representative-environment acceptance: Not Run or Blocked.

## Known limitations

- This remains an unsigned Alpha release.
- The BAT handoff must be run only after the exact-HEAD CI candidate gate succeeds.
- Automatic module installation remains independent of the host installer.
