# 灵动岛 / Qing Island

`qing.liveactivity` 是 Windows x64 独立进程模块，当前官方预览版本为 `0.1.16`、模块 API 版本为 `1`，要求工具箱 `0.3.4-alpha` 或更新版本。提供计时/倒计时、轻量 Markdown 与行内图标/数据占位符、原生悬浮层、实时 GPU 玻璃和自动 Codex 数据接入。胶囊的图标和所有文本均可编辑、清空，新配置默认空白；原生字体与设置预览跟随工具箱字体，包括导入字体。已上架官方 `modules` 分支，但不代表所有桌面任务都能被监控。

在正式版工具箱的“模块 → 导入模块 → 从仓库下载”中选择“灵动岛”即可下载安装；不需要单独的模块 Release。安装包和 SHA-256 存放在本目录 `packages/`，更新清单使用固定提交的下载地址。

模块介绍按行列出当前功能，并包含命名的玻璃参考仓库链接；新版工具箱支持介绍换行和在系统浏览器中打开链接。旧版工具箱仍可安装模块，但会显示原始介绍文本。

## 玻璃实现与代码借鉴来源

磨砂和液态玻璃使用 DXGI 桌面纹理、D3D11 GPU 模糊/折射与 DirectComposition 合成；背景不再由 GDI 截图或 CPU 模糊。文字独立上传，不参与模糊。静止背景通过 GPU 区域比较避免重复绘制，隐藏后释放采集，显示器或会话变化后重建，暂时不可用时回退半透明并定时尝试恢复。

- [hicccc77/electron-liquid-glass](https://github.com/hicccc77/electron-liquid-glass)：MIT；借鉴原生采集/合成管线、分离模糊与折射的思路，不引入 Electron。
- [poncippg-spec/liquidDX11](https://github.com/poncippg-spec/liquidDX11)：上游原始代码声明为 MIT；借鉴桌面玻璃、SDF 轮廓及边缘光照思路，不引入其 ImGui、字体或图标。

本项目 Rust/HLSL 集成、区域比较和胶囊交互独立实现。参考提交、借鉴边界及完整许可见随包附带的 [third-party/GLASS-SOURCES.md](third-party/GLASS-SOURCES.md)。设置页“玻璃实现 · 借鉴来源”也可点击打开对应仓库。

## 当前可用能力

- Win32 原生悬浮层：无边框、置顶、不激活、不显示任务栏按钮；透明圆角区域不接受点击。
- 常驻、悬停和展开三个 Markdown 文本独立编辑；图标与右侧布局均融入文本，不再单设内容位置。`{icon.clock}` 时钟和 `{icon.status}` 任务状态可放在任意文字之间，也可直接输入符号/Emoji。`{space}` 把所在行分到左右两端，同一行仅最后一个生效、之前的忽略。日期和时间通过 `{date}`、`{weekday}`、`{time}` 自行添加，支持 12/24 小时和秒数。模板最多 1024 个 Unicode 字符，每段解析后最多 256 字、16 行，屏幕空间不足时换行或省略。
- 原生文字跟随宿主所选系统字体或导入的 TTF/OTF/TTC；运行时约每秒检测宿主设置变化，设置页关闭后仍生效。Dev 和正式版按宿主传入的数据目录区分字体配置，不串用。导入字体只在模块进程内注册，不进行全局安装；校验失败或文件缺失时回退默认字体并记录诊断。
- 实色、半透明、自绘磨砂、液态玻璃和果冻；磨砂散射背景、液态玻璃折射背景，文字独立合成保持清晰；果冻有浓淡边缘、光泽与挤压回弹动画。
- 没有活动和常驻内容时隐藏；有内容时显示 Compact，悬停可进入 Peek，点击展开显示展开文本。鼠标离开后收起。
- 本地时钟可独立显示；计时器/倒计时、任务、Codex 数据仅通过用户的三段文本模板中的占位符显示，不自动附加文字。任务只额外改变状态圆点的颜色与进度环。
- 六个停靠点（左上/顶部居中/右上/左下/底部居中/右下）、主屏/鼠标所在屏、横纵位置微调、200–480 逻辑像素胶囊宽度和 75%–150% 整体缩放，以及全屏时始终显示/隐藏/仅显示重要活动。
- 活动按优先级排序：等待用户和失败优先；成功、失败等终态到期后退出，不因重复快照无限续期。
- Mock 可产生运行、等待、成功、失败、进度和组合场景；清空后不会从模拟缓存重新出现。
- Vue 设置页复用工具箱 Module UI 和外观 SDK，支持宿主深浅主题、五种皮肤和窄窗口布局。原生胶囊使用独立的深色高对比绘制，不依赖 WebView。
- 诊断页提供最多 256 条内存日志；不记录对话正文、密钥或账号凭据，模块卸载后日志不保留。

## Codex 能力边界

模块启用且“启用灵动岛”打开后，每 5 秒用 Windows 进程快照检查外部 `codex.exe` 是否运行，只读取程序名和父子进程 ID。发现后优先用已安装 CLI 的 `codex app-server proxy` 连接已运行服务的官方本地控制端点；不可用或 CLI 不支持时，自动退回独立 `codex app-server`，**仅读取账号额度，不把它的空线程列表当成桌面工作状态**。自己的辅助进程和其他灵动岛实例的进程树均排除；外部 Codex 退出后回收采集辅助进程，但保留最后成功读取的数据并标注缓存，程序再次启动时自动恢复。不会启动、重启或停止外部 Codex 服务。检测失败则暂停采集并显示原因。进程检测使用 [Windows Tool Help 快照 API](https://learn.microsoft.com/en-us/windows/win32/api/tlhelp32/nf-tlhelp32-createtoolhelp32snapshot)，读取协议参考 [Codex app-server 官方文档](https://learn.chatgpt.com/docs/app-server)。

读取失败、断线、暂停及部分字段缺失都不会擦除已有数据；恢复成功读取后才替换旧值。额度卡片显示缓存标志和最后成功时间，旧任务状态显示“上次观察／当前未确认”，不作为当前正在运行的活动。最后成功读取超过 30 秒也标记过期。缓存仅保存在模块进程内，停用再启用可保留，卸载或进程重启后不保留；不把账号数据写入磁盘。

设置页明确区分“共享实例 · 工作/等待数量”和“仅额度连接 · 桌面任务未接入”。共享实例只展示该服务 `thread/loaded/list` 的线程，并以 `thread/read(includeTurns:false)` 的运行状态判断工作或等待；不读取对话正文，不恢复线程，不读取磁盘历史列表。没有共享端点的普通桌面实例仍无法监控，不能宣称“0 个任务”就是桌面空闲。

共享接入需要对应 Codex 实例真正开放兼容的官方本地控制端点，CLI `proxy` 连接的是默认端点。模块不扫描端口、劫持 stdio、打开私有 IPC 或修改用户配置。仅额度模式每 60 秒再尝试共享接入；手动刷新可提前重试。未发现端点时仍提供真实账号额度。两种模式都由模块管理自己的辅助进程；退出只关闭代理/采集子进程，不关闭共享服务。

- 不采集其他进程内存、私有数据库、私有套接字或桌面聊天内容。
- 传输层仅允许初始化、已加载线程列表、不含正文的线程读取和额度读取；拒绝开始/恢复线程、发起对话、登录和中断等调用。共享服务的交互请求既不批准也不拒绝，不干预原客户端的确认。活动中的 action 字段只是元数据，不代表可代用户批准。
- 账号额度与任务 token/context 用量不同；没有真实任务用量时省略，不使用额度百分比填充。
- RPC 在独立工作线程执行，避免阻塞宿主操作和原生绘制。主动刷新可以跳过读取间隔/重连退避；常规读取间隔 10 秒，失败重连退避 30 秒。
- 采集自动跟随程序存在状态，不再有手动连接开关或空闲关闭设置。显示开关和文本位置不控制采集生命周期；停用灵动岛、停用或卸载模块均回收受控进程树。

媒体、下载、文件传输等真实 Provider 尚未实现；当前悬浮层测试使用 Mock，不对这些任务作自动监控承诺。

## 生命周期与使用

1. 在工具箱模块页加载并启用“灵动岛”。加载只是驻留进程，不自动运行 Provider。
2. 打开设置页，勾选“启用灵动岛”。在“显示内容”中添加图标或文本，可点击占位符插入时间、计时或 Codex 数据；新配置不会自动添加时钟和日期。两个开关均启用后才进行持续工作。
3. “预览”可在模块停用时临时显示，30 秒后自动结束；关闭设置页会结束预览，但不会停用或卸载模块。
4. “停用”终止 Provider、清空活动、隐藏悬浮层，模块进程继续驻留；再次启用可恢复。卸载则退出模块和受控子进程。

`module.json` 使用宿主已支持的 `Process` / `OutOfProcess` / `Web` / `Startup` 契约，没有增加不存在的 Background 枚举。是否随工具箱启动由宿主授权控制，不注册 Windows 自启动。

新配置默认灵动岛关闭、Codex 数据显示开启，启用灵动岛后才开始程序检测。配置保存到宿主提供的 `QINGTOOLBOX_MODULE_DATA_DIR/settings.json`，保存失败时不切换内存状态。独立调试需自行提供隔离的数据目录。schema 6 兼容 schema 1–5，保留外观、位置和已有文本；旧时钟、日期、图标、右侧的一次性迁移见下文。`codexEnabled` 迁移为只控制显示的 `showCodexData`，退休的 `codexDataPosition` 被忽略。API 1 仍接受旧 patch 但不恢复额度预设，历史 `island.account`/`accountHeader` 返回 null。旧 `showClock` 不再控制任何隐式文字，时间需写入模板。宿主字体为运行时信息，不写进模块配置。

## 外部数据显示与文本占位符

目前真实外部数据源只有 Codex。胶囊中的额度、距重置时间、最近读取时间仅由自定义文本占位符决定，不再提供显示位置预设，也不绘制内置额度行。没有模板引用时不主动显示额度。关闭“在文本中显示 Codex 数据”后，所有模板中的 Codex 数值使用缺省文本，但后台采集不受影响。设置页的数据源卡片保留额度和连接状态，供查看与诊断，不代表胶囊自动显示这些内容。

自定义文本下方的按钮可在输入光标处插入占位符，编辑后点击“保存”。支持：

- `{time}`、`{date}`、`{weekday}`：本地时间、日期和星期（例如“一”）。
- `{stopwatch}`、`{countdown}`：计时器/倒计时的读数，未开始的倒计时显示设定时长；可用对应 `.state` 占位符显示运行状态。
- `{codex.remaining}`、`{codex.reset}`：优先主额度、主额度未提供百分比时使用次额度；剩余百分比与距重置时间。
- `{codex.primary.remaining}`、`{codex.primary.reset}`：主额度。
- `{codex.secondary.remaining}`、`{codex.secondary.reset}`：次额度。
- `{codex.updated}`：最近成功读取时间（本地月日/时分）。
- `{codex.state}`：共享实例最后观察到的任务状态；过期时明确显示“上次……（当前未确认）”。
- `{codex.freshness}`：已更新／上次数据／未读取；`{codex.threads.updated}`：最近成功读取任务状态的时间。

“无数据时的文本”是所有占位符共用的缺省值，默认“暂无数据”，留空则该占位符不显示。`{key|替代文本}` 为单个占位符覆盖缺省值，例如 `剩余 {codex.remaining|暂无额度} · {codex.reset|等待 Codex}`。从未读到该字段或关闭数据显示时使用缺省值；已有数据但暂时读取失败时继续显示旧值，额度追加“（缓存）”，任务数量追加“（上次）”。`0%` 是真实数据，不当成缺失。

模板采用有限的安全 Markdown 方言，不是完整 Markdown 引擎：支持 `**加粗**` / `__加粗__`、`*斜体*` / `_斜体_`、`~~删除线~~`、三重标记加粗斜体，以及反引号包裹的等宽原文。展开文本支持换行；第一行字号较大，但加粗由用户标记控制。暂不支持标题 `#`、链接、图片、列表或 HTML。不执行脚本、HTML、表达式或递归替换；外部数据与缺省文字始终视为字面文本，不能产生新图标、格式或左右分隔。未知占位符保留原样；反斜杠可转义语法，`{{`/`}}` 输出字面花括号。反引号内不解析任何占位符。Rust 与 Vue 使用同一组原生数据值和 `contracts/rich-text-v1.json` 契约测试，切换页签和隐藏数据不启动/终止 Provider。

“常驻／悬停／展开”分别保存到 `customText`、`peekText`、`expandedText`，共享数据源和缺省值。只有展开支持编辑换行；切换页签同时切换对应预览，插入占位符只修改当前草稿。格式按钮可包裹选中文字，图标与分隔按钮可在光标处插入。后台刷新不会覆盖未保存草稿。展开编辑器中 Ctrl+Enter 可保存，普通 Enter 插入换行。图标为本地原生矢量绘制，无固定首位留白，不提供图片文件导入。`{space}` 不显示字符，右侧为空时不会预留空白；多次出现时仅最后一个分隔有效，其他分隔直接移除，逐行独立。

例如常驻文本 `**专注** {icon.clock}{space}{time}`：左侧是加粗的“专注”和时钟图标，右侧是时间；`左{space}中{space}右` 等同于 `左中{space}右`。只要输入 `文字 {icon.status} 文字`，状态图标就在两段文字中间。等宽文本使用 Consolas；其他原生字体仍跟随宿主。

新配置三段文本均为空白。schema 1–3 的旧隐式悬停/展开内容先按原规则转为显式模板；schema 4 中已清空的悬停/展开保持空白。旧时钟开启时，空常驻文字转为 `{date} · 周{weekday}`，右侧转为 `{time}`，图标转为 `{icon.clock}`。schema 6 将旧图标放到常驻文本前、旧右侧内容加在 `{space}` 后，然后清空兼容字段 `iconText` / `rightText`；旧普通文本的 Markdown 标记及新布局指令被转义，避免突然变成格式。迁移只执行一次，已清空的内容不会被补回。

所有正文只使用对应模板，不再回退到日期、模块名、任务进度或内置提示。任务不自动生成列表行或附加文字，展开卡片只绘制展开模板（第一行作为标题）；需要任务信息时自行写 `{task}`、`{task.state}`、`{tasks}` 等占位符。没有图标时不保留图标占位；只有悬停/展开内容时保留一个空白胶囊入口。过长文本在可用空间内换行或省略。

## 计时与遮挡处理

计时器（秒表）和倒计时可以同时运行，各有开始/继续、暂停、重置。倒计时默认 5 分钟，允许 1 秒–7 天，设置页运行时锁定时长输入；暂停后修改会重置，API 修改时长同样重置而不改变正在运行的目标。计时以原生单调时间计算，不依赖 Vue 刷新次数或墙上时钟调整；关闭设置页、隐藏胶囊或关闭数据显示都不会停止计时。停用模块/关闭“启用灵动岛”会暂停，重新启用不自动继续。卸载/进程重启不恢复正在运行的计时，避免突然触发过期提醒。

计时器不会自动往胶囊里写任何文字，只提供占位符：`{stopwatch}`、`{countdown}` 为读数（未开始的倒计时显示设定时长），`{stopwatch.state}`、`{countdown.state}` 为“未开始／进行中／已暂停／已结束”。放在哪段文本、前后配什么字完全由用户决定，例如常驻 `专注 {countdown}`、悬停 `倒计时{countdown.state}`。设置页的计时卡片会标出它已被哪段文本引用，并可一键插入占位符。旧的 `showStopwatch`/`showCountdown` 字段仅为兼容保留，不再有任何效果。倒计时完成只记录一次日志。

## 占位符一览

| 来源 | 占位符 |
| --- | --- |
| 时间 | `{time}` `{date}` `{weekday}` |
| 计时 | `{stopwatch}` `{stopwatch.state}` `{countdown}` `{countdown.state}` |
| 任务（模拟、Codex 等所有任务来源） | `{task}` 当前任务标题、`{task.state}` 状态、`{task.detail}` 说明、`{task.progress}` 进度百分比、`{task.source}` 来源、`{tasks}` 最多三行“标题 · 进度/状态”、`{tasks.count}` 任务数量 |
| Codex | `{codex.working}` `{codex.waiting}` `{codex.state}` `{codex.threads.updated}`（共享实例观察）、`{codex.remaining}` `{codex.reset}` 及主/次额度、`{codex.updated}` `{codex.freshness}` |

每个占位符都可写成 `{key|缺省文字}` 单独指定无数据时显示的内容。今后新增的数据来源同样只以占位符形式提供数据。

“遮挡处理”提供鼠标穿透与“隐藏 30 秒/恢复显示”。穿透用分层窗口的 `WS_EX_TRANSPARENT` 把输入交给下方窗口，胶囊不再接收悬停/点击，返回本模块设置即可关闭；设置页不跟随穿透。临时隐藏使用后台计时，到期自动恢复，也可以提前恢复；计时和数据采集不停。依据 [Windows 分层窗口文档](https://learn.microsoft.com/en-us/windows/win32/winmsg/window-features#layered-windows) 实现，不采用模拟点击下方窗口。原有位置、尺寸和全屏隐藏设置继续有效。

Codex 程序发现顺序为显式 `QINGTOOLBOX_CODEX_PATH`、PATH/常见 CLI 目录、桌面版的 `%LOCALAPPDATA%/OpenAI/Codex/bin`（只检查当前目录及最多 128 个直接版本子目录）。桌面版备用路径不依赖工具箱继承 Codex 专用 PATH，不扫描会话或凭据文件，旧设置保持兼容。

外观支持 RGB（0–255）输入、系统取色器、八种常用底色（果冻材质时换成八种糖果色）和恢复默认。颜色同时应用于原生悬浮层和设置预览，浅色自动使用深色文字；文字覆盖率与文字颜色独立，黑色文字也保持不透明。五种材质，其中磨砂玻璃、液态玻璃与果冻是三种本质不同的东西——磨砂靠散射，液态玻璃靠折射，果冻靠弹性：

- 实色：完全遮住背景。
- 半透明：保留清晰背景。
- 磨砂玻璃（平、雾、柔）：背景通过 GPU 两次分离高斯模糊，默认 6 逻辑像素、0–40 可调；轻微增饱和并叠加可调着色，只有一条细而均匀的边。最低强度不着色，最高约 72% 着色。
- 液态玻璃（透、折、厚、流）：真实桌面纹理轻度柔化，圆角 SDF 边缘连续折射并带轻微色散；中央保持可辨认，边缘显示厚度、高光和阴影。指针悬停时高光方向跟随，尺寸形变仍用流体曲线；中性文字随背后的局部亮度适配深浅，文字不被模糊。最低强度不着色，最高约 40% 着色。
- 果冻（软、弹）：不是玻璃，是半透明的软胶实体。颜色就是主体（中心密度 55%–95%），边缘更深更厚、圆润柔软，内部有向下偏的散射光，上部有一大片柔和高光，沿上沿一道柔光唇线；不采样桌面，背景不重要。运动有惯性：变化最大的一边约 114% → 98% → 100% 回弹，另一边反向挤压（拉伸一边、压扁另一边），约 640 毫秒。选中果冻时颜色行换成八种糖果色。

其他材质仍是约 140 毫秒无回弹的缓出。

透明材质强度越高，着色越强；“推荐强度”仍为 60%，切换材质不覆盖用户保存的强度或颜色。拖动外观滑块或系统取色器时，桌面胶囊实时跟随（`previewSettings`，只改内存），松手才保存。设置预览使用示意桌面，不读取真实桌面；原生磨砂与液态玻璃读取本机实时 GPU 桌面纹理。

设置页顶部是“实时预览”舞台：示意桌面上的胶囊按停靠位置、偏移、宽度、缩放、材质和颜色实时摆放，右侧是模拟活动与桌面上的活动列表；“启用灵动岛”总开关位于页头。其下依次为材质与颜色（五种材质对照）、位置和尺寸（显示器式六向停靠）、显示内容（三种状态文本、即时效果预览与占位符）、计时与倒计时（表盘与常用时长）、行为、数据来源和诊断；窄窗口自动改为单列。预览可独立切换胶囊/悬停/展开，不跟随后台活动跳变。示意桌面随工具箱皮肤变化，胶囊本身始终按原生绘制规则显示：液态玻璃用 SVG 位移滤镜真实折射舞台内容（浏览器只能折射元素自身范围内的背景，所以网页预览的边缘向内折射，原生窗口向外折射），高光随指针移动；果冻与液态玻璃的尺寸动画使用与原生同一组曲线；壁纸漂移在舞台离开视口时暂停，网页预览遵循系统减少动画偏好。

预览卡片随页面正常滚动，不吸附或覆盖后面的设置。Codex 卡片独立展示主/次两组账号额度的剩余百分比、官方重置时间（本地时间）和最近成功读取时间；从未读到的字段显示未知，失败或字段缺失时保留旧值并标明缓存，手动刷新可重试。额度后台每 10 秒读取一次，`account/rateLimits/updated` 通知会提前触发读取。额度不是精确的剩余 token 数，也不是其他 Codex 窗口的上下文 token 用量。模板引用额度时，额度变化会主动更新对应的原生文本，不等待时钟跳到下一分钟。

例如，常驻文本填写 `剩余 {codex.remaining|暂无额度}`，悬停填写 `{codex.reset|等待 Codex}`，展开填写 `主额度 {codex.primary.remaining}\n次额度 {codex.secondary.remaining}`（在编辑器里实际换行）。只显示本地时间或普通文字时不会因为额度连接、断开或变化而添加行或改变窗口尺寸；真实任务列表和独立计时功能保持不变。

位置偏移使用逻辑像素：正 X 向右、正 Y 向下，范围各为 -4096–4096。实际窗口按当前屏幕 DPI 换算并限制在工作区内，角落停靠展开时保持对应边缘，不突然跳回居中；预览中的位置按虚拟屏幕比例示意。宽度影响三种可见状态，整体缩放同时影响宽高和文字。旧配置没有这些字段时沿用 232 宽度、零偏移和原先的停靠点，点击“复位”恢复默认位置尺寸。

原生窗口首次需要显示时创建，无内容时隐藏并复用至卸载；切换材质只重建本模块悬浮窗。静态画面不持续重绘，尺寸过渡（约 140 毫秒；液态玻璃约 420 毫秒，果冻约 640 毫秒）才启用帧调度，动画帧用 `DwmFlush` 对齐显示器刷新率（60/120/144 Hz），其他定时等待使用高精度可等待计时器，不受 15.6 ms 系统时钟粒度影响；液态玻璃仅在指针悬停并移动时按指针重绘；没有时钟、没有活动且程序未运行时，仅保留低频程序检测（必要时另检查全屏策略），不因隐藏数据而停止检测。只显示分钟时不会因为时钟每秒重绘。显示器/DPI/工作区变更通过原生消息重新布局。

配置页每 1.5 秒静默读取状态，不把后台读取当成用户操作，不因此禁用控件或重放动画。读取单请求串行；拖动或编辑期间暂停，交互开始/保存/页面关闭会使旧请求失效，避免迟到的快照覆盖新设置或草稿。`ui-src` 中的 `npm test` 检查刷新门控（需支持 TypeScript 类型剥离的 Node.js），宿主界面检查另外验证持续拖动跨越刷新周期仍可保存。

磨砂与液态玻璃都由模块自己实现，不依赖激活状态相关的 Desktop Acrylic：读取胶囊覆盖范围及其周边背景。磨砂降采样后做三次可分离盒式模糊；液态玻璃保留全分辨率，另备一份半分辨率柔化的面板图，边缘用原图折射。读取时双线性插值，再合成着色、高光和清晰文字。桌面采样与前景动画分离：磨砂背景变化时约 10 次/秒、静止后约 4 次/秒；液态玻璃约 15 次/秒、静止后约 5 次/秒。指针高光、折射参数、文字与尺寸动画仍按显示器帧率使用缓存背景重绘，不受采样频率限制。采样包含 DWM 合成的普通窗口与分层/半透明窗口，灵动岛自身通过 `WDA_EXCLUDEFROMCAPTURE` 排除；这保证胶囊内显示的确实是其后方内容，而不是壁纸或旧像素。窗口位置和尺寸不变时不重复提交 HWND 几何，高开销的合成采样也保持有界频率，以降低 DWM 与显卡驱动负担。尺寸动画期间只采样一次覆盖起止范围的区域，整个动画复用，不逐帧截屏。液态玻璃的面板在半分辨率上柔化，边缘折射使用原始分辨率。合成按行并行（大面积时最多 6 个线程），胶囊内部像素走快速路径，文字层在文字、尺寸和墨色不变时直接复用；背景、尺寸、指针、文字都没变的帧直接跳过。release 构建使用 `opt-level = 3`，逐像素循环依赖向量化与内联。可用 `cargo test --release live_frame_rate -- --ignored --nocapture` 在已解锁桌面上复测，`frame_budget` 给出分环节耗时。背景不变时复用处理结果，合成像素不变则不提交新窗口帧。隐藏、停用或卸载时停止采样并清空缓存。诊断只记录采样次数和耗时，不记录背景像素。

背景像素仅在本机内存中短暂使用，正常运行不保存、不上传。为防止递归采到自己，磨砂和液态玻璃通过 `WDA_EXCLUDEFROMCAPTURE` 将本模块窗口排除出系统截屏，因此截图/录屏通常不会包含灵动岛；切回其他材质恢复正常截屏。需要 Windows 10 2004 或更新版本及可用的桌面合成，系统不支持或采样失败时回退半透明并显示原因，不修改其他窗口的保护设置、不绕过受保护画面。

## 源码分工

```text
Provider → LiveActivity → Broker → Priority Resolver → IslandModel → Win32 Renderer
```

- `src/activity.rs`：跨 Provider 数据模型。
- `src/broker.rs`、`src/priority.rs`：校验、稳定排序、去重、终态到期及容量限制。
- `src/overlay.rs`、`src/display.rs`、`src/fullscreen.rs`：可独立测试的状态机、尺寸与策略。
- `src/ambient.rs`：本地时间格式、日期与自定义文本；不进入活动 Broker。
- `src/programs.rs`：有界进程存在检测、辅助进程树排除与自动采集触发。
- `src/text_template.rs`：原生数据占位符和缺省值；`src/rich_text.rs`：安全的 Markdown / 行内图标 / 逐行左右对齐 AST；`contracts/rich-text-v1.json`：跨 Rust / Vue 语法用例。
- `src/timers.rs`：单调计时、暂停/继续、独立倒计时及一次性完成状态。
- `src/win32.rs`、`src/renderer.rs`：窗口消息、点击区域、局部背景采样、材质回退与 CPU 透明绘制。
- `src/blur.rs`：有界 RGB 模糊及着色，文字不进入模糊管线。
- `src/providers/mock.rs`：有界模拟数据。
- `src/providers/codex/`：官方协议解析、受控进程、取消/退出和独立工作线程。
- `src/main.rs`：宿主模块协议、生命周期、预览、工作调度。
- `ui-src/`：仅作为配置/诊断界面，不承担后台活动的生命周期。

Broker 和 Mock 各最多保存 32 个活动；诊断和 app-server 输入队列也有上限。权限为 `ProcessStart`（自动 Codex 数据源）和 `WindowControl`（原生悬浮层），不申请任意文件选择或网络模块能力。

## 构建与本地检查

在 modules 分支工作区执行，`HostRoot` 指向对应的 toolbox 分支工作区：

```powershell
cargo test --manifest-path modules/LiveActivity/Cargo.toml --locked
cargo clippy --manifest-path modules/LiveActivity/Cargo.toml --locked --all-targets -- -D warnings
.\scripts\build-module.ps1 -Module liveactivity -QingToolboxHostRoot <HostRoot>
```

在 toolbox 分支工作区执行：

```powershell
.\scripts\smoke-tauri-liveactivity.ps1 -ExecutablePath .\QingToolbox.Tauri\src-tauri\resources\modules\qing.liveactivity\bin\qing-liveactivity-module.exe
.\scripts\package-tauri-module.ps1 -ModuleId qing.liveactivity -SkipBuild -Smoke
```

smoke 使用临时配置验证宿主协议、加载/停用/重新启用、原生可见窗口/样式/命中测试、时钟/文本/材质、不抢焦点、清空、终态隐藏、空闲停止重绘及磨砂隐藏后停止采样。可选 `-CaptureDirectory <Path>` 在测试自建彩色背景上保存实色/半透明截图，磨砂因排除截屏而跳过；`-CheckCodex` 仅执行本机 CLI 初始化与只读 RPC，不发起任务或代替用户授权。`-CheckNativeClick` 显式启用真实鼠标点击，验证三种材质、上下停靠时自定义文本留空仍可正常展开；只点击隔离模块的窗口，并在结束时恢复鼠标位置。需要已解锁桌面，检查期间不要操作鼠标。

在已解锁的 Windows 桌面上，可显式运行原生磨砂集成检查：

```powershell
cargo test --manifest-path modules/LiveActivity/Cargo.toml --locked native_glass_blurs_background -- --ignored --nocapture
```

该检查在完全覆盖采样区域的自建条纹窗口上验证真实背景模糊、颜色保留、文字清晰、可见时不递归采入自身及静态帧去重，同时覆盖三种材质、三种缩放及动画中间尺寸下的空文本展开绘制。可设置 `QING_ISLAND_TEST_IMAGE` 指定 BMP 输出，仅测试构建支持此输出；正常模块没有图像导出入口。

原生胶囊的绘制（状态圆点与光晕、进度环、时钟表盘、玻璃边缘高光、展开标题排版、尺寸动画中正文淡入）由 `renderer::compose` 离屏完成，普通 `cargo test` 即会在无窗口条件下渲染全部状态并断言；设置 `QING_ISLAND_GALLERY=<目录>` 可把每个状态另存为 BMP 供人工查看。设置页预览 `IslandPreview.vue` 镜像同一套逻辑像素布局与配色，两者需同步修改。

`node scripts/smoke-tauri-liveactivity-window.mjs` 另起一个隔离配置的开发宿主，验证设置页、五种皮肤、480 像素布局、预览及关闭 UI 后继续驻留，生成截图到 `artifacts/ui-check/liveactivity/`；不会覆盖正式版数据。需要先存在宿主 debug 可执行文件及前端依赖。

构建产物进入宿主开发资源目录，`.qmod` 打包仍走通用模块流程。官方目录已将本模块标记为公开预览，`update.json` 记录版本、固定提交下载地址、大小和 SHA-256。新增真实 Provider 将通过后续模块版本发布，不影响当前时钟、文本和账号额度功能。
